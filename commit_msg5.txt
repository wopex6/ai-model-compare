MIGRATION: Unified Dynamic Character System

PROBLEM:
Duplicate route registration for Coach, Sage, and Marcus characters.
Two systems (static + dynamic) maintained separately, creating:
- Maintenance overhead (update both systems)
- Code duplication (~500 lines)
- Inconsistency risk
- Harder to add features

SOLUTION:
Migrated ALL characters to unified dynamic character system.

WHAT CHANGED:

1. Frontend Templates (3 files):
   - motivational_coach.html: URLs updated
     * /coach/chat → /super_motivational_coach/chat
     * /coach/stats → /super_motivational_coach/stats
   
   - wisdom_sage.html: URLs updated
     * /sage/chat → /wisdom_sage/chat
     * /sage/stats → /wisdom_sage/stats
     * /sage/daily-wisdom → /wisdom_sage/daily-insight
     * Response field: daily_wisdom → insight
   
   - stoic_marcus.html: URLs updated
     * /marcus/chat → /stoic_philosopher/chat
     * /marcus/stats → /stoic_philosopher/stats
     * /marcus/daily-reflection → /stoic_philosopher/daily-insight
     * Response format: simplified to insight field

2. Backend Routes (app.py):
   DELETED (~500 lines):
   - @app.route('/coach') - page route
   - @app.route('/coach/chat') - chat endpoint
   - @app.route('/coach/stats') - stats endpoint
   - @app.route('/sage') - page route
   - @app.route('/sage/chat') - chat endpoint
   - @app.route('/sage/stats') - stats endpoint
   - @app.route('/sage/daily-wisdom') - daily wisdom endpoint
   - @app.route('/marcus') - page route
   - @app.route('/marcus/chat') - chat endpoint
   - @app.route('/marcus/stats') - stats endpoint
   - @app.route('/marcus/daily-reflection') - daily reflection endpoint
   
   KEPT (special functionality):
   - @app.route('/coach/toggle-reminders') - Coach-specific feature

3. Dynamic System (character_routes.py):
   NOW HANDLES ALL 8 CHARACTERS:
   - super_motivational_coach (Coach)
   - wisdom_sage (Sage)
   - stoic_philosopher (Marcus)
   - psychologist (Dr. Elena)
   - zen_master (Master Kai)
   - business_coach (Coach Ryan)
   - life_coach (Coach Jordan)
   - scientist (Dr. Nova)
