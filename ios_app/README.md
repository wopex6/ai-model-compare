# AI Model Compare iOS App

A native iOS app for comparing and interacting with multiple AI models, supporting iPhone 7 Plus through iPhone 14.

## Features
- Multiple AI model comparisons
- Real-time chat interface
- Model performance metrics
- Offline capability with sync
- Voice input/output
- Dark/light theme
- Accessibility support

## Requirements
- iOS 13.0+ (iPhone 7 Plus compatibility)
- Xcode 14+
- Swift 5.7+

## Architecture
- MVVM pattern
- Combine for reactive programming
- Core Data for persistence
- URLSession for networking
- AVFoundation for voice features
