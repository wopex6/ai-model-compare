### 🚀 **Quick Installation Steps:**

1. **Copy Project to Mac** (if not already on Mac)
   ```
   Source: c:\Users\trabc\CascadeProjects\ai-model-compare - Claude\ios_app\AIModelCompare
   ```

2. **Open in Xcode**
   ```
   Open: AIModelCompare.xcodeproj
   ```

3. **Configure Xcode**
   - Select your Apple Developer account
   - Change Bundle ID to: `com.aicompare.dev.28342`
   - Connect iPhone to Mac
   - Select iPhone from device dropdown

4. **Build & Run**
   ```
   Press: Cmd+R
   ```

5. **Trust Developer Certificate** (on iPhone)
   ```
   Settings → General → VPN & Device Management → Trust Developer
   ```
