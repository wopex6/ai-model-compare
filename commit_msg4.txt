ENHANCEMENT: Context-Aware Quick Replies

PROBLEM IDENTIFIED:
Quick replies (cached strategy responses) were instant and free,
but completely ignored user's explicit context. Generic advice
worked technically, but missed personalization opportunity.

SOLUTION:
Made quick replies context-aware while maintaining speed and cost benefits.

IMPLEMENTATION:

1. base_enhanced_chatbot.py:
   - Modified _provide_strategy() to extract context from message
   - Added _extract_context_from_message() helper
   - Added _build_context_aware_intro() for personalized intros
   - Context-aware closing that references user's goal

2. psychologist_chatbot.py:
   - Updated _provide_coping_strategies() to use context
   - Personalized intro based on emotion + goal
   - Context-aware closing

WHAT CHANGED:

Before (Generic Quick Reply):
```
**Managing Anxiety**

Here are evidence-based strategies for managing anxiety:
1. 4-7-8 Breathing: Inhale 4 counts, hold 7, exhale 8...
...
Would you like me to walk you through one of these techniques?
```

After (Context-Aware Quick Reply):
```
**Managing Anxiety**

I can see you're dealing with anxious while working toward 
become a data scientist. That's a challenging combination, 
and it's completely understandable. Here are evidence-based 
strategies specifically for managing anxiety:

1. 4-7-8 Breathing: Inhale 4 counts, hold 7, exhale 8...
...

💡 Remember: These strategies can help you stay focused on 
become a data scientist while managing anxious.
```

BENEFITS:

✅ SPEED: Still instant (no AI call needed)
✅ COST: Still free (cached response)
✅ PERSONALIZATION: Now acknowledges user's situation
✅ EMPATHY: Shows understanding of their specific challenge
✅ RELEVANCE: Connects strategies to their goal

HOW IT WORKS:

1. Smart Response prepends context to message
2. Quick reply detector triggers on keywords
3. Context extracted from prepended section
4. Template filled with personalized intro/closing
5. Evidence-based techniques (universal, unchanged)

CONTEXT EXTRACTION:

Parses Smart Response context format:
- "Current emotional state: X" → emotion
- "Goal: Y" → goal
- "Preference: Z" → preference

Then builds personalized response around these.

TESTING:

Old test result: Generic "Here are strategies..."
New test result (expected): "I see you're stressed about data science goals..."

Next test: Send same 5 messages, verify last response
now mentions stress AND data science goal.

IMPACT:

Quick replies now deliver:
- 🎯 Personalization (context-aware)
- ⚡ Speed (instant response)
- 💰 Savings (no AI cost)

Best of both worlds: Fast AND personalized!
