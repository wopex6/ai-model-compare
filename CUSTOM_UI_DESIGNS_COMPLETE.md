## 📝 **Technical Notes**

### **Template System**
- Characters specify `custom_template` in config
- Falls back to `character_universal.html` if not specified
- Allows mix of custom and universal templates

### **Configuration**
```python
# In character_configs.py
"zen_master": {
    ...
    "custom_template": "zen_master.html",
    ...
}
```

### **Route Registration**
```python
# character_routes.py automatically detects
template = config.get('custom_template', 'character_universal.html')
return render_template(template, character=info, character_id=character_id)
```
